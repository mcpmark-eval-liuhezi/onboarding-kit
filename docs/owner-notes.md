# Owner Notes

## Maintainers

This checklist is maintained by the team lead, **Hezi Liu** ( [@HeziLiu](https://github.com/HeziLiu) ).

If you're unsure whether something in the checklist still applies, or you spot a gap, open an issue or a pull request in this repository and tag the maintainer.

## Review cadence

The onboarding checklist is reviewed **quarterly**. During each review, the maintainer should:

- Confirm every checklist item still reflects the current tooling, accounts, and team processes
- Remove items that are obsolete and add new ones as the team's workflow evolves
- Incorporate recent feedback from new hires (see the "Collect feedback from new hires" sub-issue)
- Commit changes on a branch and merge through a pull request, in line with the team's normal workflow
